# @heyramzi/ui/panel

`SidePanel`, a sheet for one record: badges, links out to other tools, a copy-a-prompt handoff and a stats strip. `PanelStat` types one stat. It used to live in `@heyramzi/ui/work`, which still re-exports both, and `tasks/side-panel` still resolves.

Exports: `SidePanel` and the types `PanelStat`, `SidePanelWidth`.
