# The shell a Bash call gets

Every Bash call starts a fresh shell at the repo root, and the transcript says `Shell cwd was reset to ...` after any call that changed directory. Write absolute paths, or `cd` inside the same call. A `cd` on one call and the work on the next is the most common wasted call in this workspace.

zsh and macOS, each one a round trip lost before. The `command-guard` hook refuses the ones it can see and says what to write instead. These it can't:

- A `pnpm` or `npx` call inside `while read` eats the loop's stdin, so the loop stops after the first row. Give it `</dev/null`.
- An agent isolated in a worktree gets refused any command whose path isn't literal: `cd "$(...)"`, `git -C "${W}"`, an alias, a nested substitution, a loop variable (`for p in ...; do find "$p"`). Write the absolute path out, one command per path (5 refusals in one upgrade run, 2 Nov 2026; 11 across one refactor night, 5 Nov 2026). A heredoc (`cat > f <<'EOF'`, `python3 - <<'EOF'`) and a brace list (`{fr,es}.ts`) are refused the same way: write the file or the commit message with the Write tool and name each path (4 refusals across 13 agents, 10 Nov 2026). So is git fed its paths by `xargs`: run `git log -1 -- <path>` once per path (Glance, 10 Nov 2026). So is `export PATH=...` in a call that also runs git: put the PATH export and the binary it's for in a call of their own (2 refusals the same night). So is git piped into `sed` or `grep`, or chained after a build (`xcodebuild ...; git status`): give git a call of its own and filter its output in the next (3 refusals, 11 Nov 2026). So is a `cd` into the shared checkout to build: a Swift build in `apple-apps/.claude/worktrees/<agent>` finds the kit through the `.claude/worktrees/upsys` symlink to `~/Studio/upsys` (each `project.yml` climbs 4 folders), so build in the worktree, and recreate that link if it's gone.
- `tmux` isn't installed, and `script -q` exits silently when its stdin isn't a terminal. A command that needs a TTY (`claude mcp login --no-browser`) runs under `python3` with `pty.fork()`, its output written to a file (10 Nov 2026).
- zsh never word-splits a variable: `F="a b"; git add $F` passes one path `a b` (`pathspec ... did not match`), and `B="--base-url X"; cmd $B` passes one flag. Write the paths or flags out, or use an array, `F=(a b); git add -- $F` (12 Nov 2026).
- Quote anything that starts with `=`. A bare `===` is equals expansion and answers `== not found`.
- `time` is a zsh keyword, so it goes first: `VAR=x time cmd` answers `parse error near 'time'`. Write `export VAR=x; time cmd` (14 Nov 2026).
- Never name a zsh variable `path`, `fpath`, `cdpath` or `manpath`. Each is tied to its search list, so `read -r path` wiped PATH and the next line said `command not found: mktemp` (4 Nov 2026). Write `file` or `p`.
- `psql "$URL"` with `URL` empty connects to this Mac's local Postgres socket and answers `database "ramzi" does not exist`, which reads like a bad remote. Write `psql "${URL:?}"` (17 Nov 2026).

Edit source with the Edit tool, never a `sed -i`, `python3 -c` or heredoc doing string replacement, because none of them can see the syntax it's breaking (a worktree agent lost 3 calls to refusals of exactly these, 11 Nov 2026). Script a change only when it repeats across many files, then typecheck right after. A scratchpad Playwright script calls `page.setDefaultTimeout(3000)` first: a locator that matches nothing otherwise waits the default 30 s before it says so, and 6 agents each lost that wait in one run (10 Nov 2026). On a live site, `page.goto` waits for `load`, never `networkidle`: analytics and beacons keep the network busy, so `networkidle` hits the timeout on a page that rendered fine (upsys-consulting.com `/uninstall`, 18 Nov 2026). To photograph an `.svg` figure, screenshot its `<img>` on a `file://` HTML page that already shows it: `fullPage` on a bare `.svg` URL hangs 30 s, an `<img src="file://...">` inside `setContent` loads nothing (about:blank can't read files), and `rsvg-convert` paints a figure styled with CSS variables all black (Locameublé figures, 17 Nov 2026). While other agents edit the same site, the dev server reloads the page under the script (`Execution context was destroyed`): retry that page once before reading it as a bug. The same goes for a 500 whose log says `Cannot read properties of null (reading 'function')` at `+layout.svelte`: Svelte's SSR context is lost for a few requests after a `program reload` (Locameublé, 12 Nov 2026). When every page, `/` included, still answers 500 a minute later (`Cannot read properties of undefined (reading 'name')` at `pourAgents`), the server is stuck: restart it, and on a repo whose `AGENTS.md` lets the session restart its port, do it and say so (Locameublé 3400, 17 Nov 2026). A scratchpad script that parses `.svelte` files loads the compiler with `createRequire("<repo>/site/package.json")("svelte/compiler")`: a named `import { parse }` from its file path fails with `Named export 'parse' not found` (10 Nov 2026). Load every package that way, by its name, and by its `node_modules/.pnpm/...` folder only when the repo doesn't link that name: Node skips `exports` on a path, so a package with no `main` (`@tailwindcss/node`) says `Cannot find module` while it's installed (13 Nov 2026). Playwright is installed as `@playwright/test`, so `require("playwright")` from an app folder says `Cannot find module` too (immo, 14 Nov 2026). to-sheets links neither name, so a scratchpad script there requires `<repo>/node_modules/.pnpm/playwright@<v>/node_modules/playwright` (it has a `main`), found with `ls node_modules/.pnpm | grep ^playwright@` (16 Nov 2026). A package whose main export is a default function (`postgres`, `satori`) loaded the same way is an object with the function on `.default`, so call `require("satori").default`: the bare `require` result throws `satori is not a function` (postgres 10 Nov, satori 12 Nov 2026). A scratchpad TypeScript script with a top-level `await` is named `.mts`: as `.ts`, with no `package.json` beside it, tsx compiles it to CommonJS and stops on `Top-level await is currently not supported with the "cjs" output format` (17 Nov 2026). Locameublé's app answers on `app.localhost:3400`: a scratchpad script that posts to `localhost:3400` gets a 308, writes nothing, and its next row read is `undefined` (17 Nov 2026). A Python `urllib` script calling a Cloudflare-fronted app sets its own `User-Agent`: the default `Python-urllib/x` gets a 403 before the app sees it, which read as a missing key in the JSON (Locameublé `/api/v1`, 12 Nov 2026).

**A svelte-check, vitest, tsc, build or Playwright run that seems hung is probably queued.** On Ramzi's Mac, `heavy-gate` gives them 3 slots: a job measured over 1.5 GB takes 2, a lighter one takes 1, and the rest are paused. A Playwright run is never paused. Check `~/bin/heavy-gate.py status` before you kill it, because a rerun just joins the back of the queue. Source: `kit/scripts/mac/README.md`.

**WebFetch saying `Unable to verify if domain X is safe to fetch` is its own check against claude.ai failing, not the site.** Fetch the page with `curl -sL -A "Mozilla/5.0"`, or the `browser` skill when it needs JavaScript: enablebanking.com answered WebFetch that way and curl with 200 (18 Nov 2026).
